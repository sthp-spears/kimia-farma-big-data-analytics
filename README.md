# Kimia Farma Business Performance Analysis

## 📌 Project Overview
Analisis kinerja penjualan Kimia Farma menggunakan BigQuery dan Looker Studio berdasarkan dataset transaksi tahun 2020–2023.

## 🛠 Tools
- Google BigQuery
- SQL
- Google Looker Studio

## 📊 Dashboard Highlights
- Total Nett Sales
- Total Nett Profit
- Total Transaksi
- Rata-rata Rating Transaksi
- Trend Nett Sales per Tahun
- Top 10 Provinsi berdasarkan Nett Sales
- Top 10 Provinsi berdasarkan Total Transaksi
- Top 5 Cabang (Rating Cabang Tinggi, Rating Transaksi Rendah)
- Distribusi Nett Profit per Provinsi
